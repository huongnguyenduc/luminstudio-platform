# Product Contract

These files are the living product contract derived from `SPEC.md` version
2.0. Update the affected contract and story when behavior changes. Do not grow
`SPEC.md` into the ongoing plan.

## Contract Map

- `overview.md`: product purpose, actors, scope, and non-goals.
- `platform-foundation.md`: system components, ownership, infrastructure, and
  developer workflow.
- `admin-and-processing.md`: product administration and asynchronous 3D asset
  processing.
- `mobile-commerce.md`: catalog, search, 3D detail, and cart behavior.
- `roadmap.md`: Phase 0 through Phase 4 and candidate epics.

## Source Hierarchy

```text
accepted user direction
  -> docs/product/*
  -> selected story packet
  -> implementation and executable proof
  -> decision records for durable tradeoffs
```
